# SABER-VR

**SABER-VR** is a virtual reality application for visualizing software behavior and structure. Developed as part of a master’s thesis at Eindhoven University of Technology, SABER-VR provides an immersive way to explore and understand complex software systems.

## Features

- Visualize software behavior and structure in an interactive 3D VR environment
- Navigate software components and call structures in real-time
- Integrates with JProfiler to display detailed runtime data
- Built with Unity for a flexible and scalable experience
